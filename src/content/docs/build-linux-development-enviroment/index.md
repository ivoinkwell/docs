开发方式有很多，我现在使用的是SSH远程连接的方式，但是之前手上只有一台笔记本，装虚拟机损耗太大，所以选择直接安装在物理机上。

## 概览

之前使用这个方案，最初的原因还是因为机器的配置，当时的机器是我现在作为PVE主机的笔记本，ThinkPad X250。

这个电脑当时的配置如下：

> - **CPU**：Intel i3-5010U
> - **Memory**：8G(DDR3L 1600Hz)
> - **Hard Disk**：500G HDD Seagate ST500LM021


### 为什么使用Debian

Debian 相比于 Fedora 和 Ubuntu，它的优势和劣势其实都源于同一个特点：**没有官方深度优化过的桌面环境** 。这意味着你需要自己动手组装，但也正因如此，你对系统的每一部分都有完全的控制权。

除了这些发行版在构建时候的客观原因外，还有一个最重要的东西 —— 软件包的丰富程度。记得之前安装 Manjaro 的时候把整个系统按照 MacOS 的方式去美化 Pamac ，但是除了 Pamac 和 AUR 之外也只有 APT 能如此了……


### 为什么使用i3-wm

我觉得主要还是两个方面，操作便捷程度以及资源占用程度。

**操作便捷程度**

这个是最不好衡量的，毕竟不同的人对于这个的标准是不一样的，像我这样，懒，所以就希望用任何软件都能不离开键盘，就算是多学一点快捷键，快捷命令也可以。但是如果对于这些不确定的反感，甚至喜欢GUI反馈信息的简洁直观，或许这个就不太适合你

**资源占用**

这个非常的明显，之前随便装一个桌面就要1G左右的内存，使用 Windows Manager 也不过就 300MB ，用处或许不明显，但是跑代码的时候冗余空间就很多了
