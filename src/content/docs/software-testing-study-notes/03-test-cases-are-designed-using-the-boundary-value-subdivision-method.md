---
title: 利用边界值划分法设计测试用例
---

边界值很好理解，就是我给你一个范围，你要测试这个范围的控制是否完善。就像我给你一个密码字数范围 `8~12` 字母及数字的组合，如果你要测试我的这个配置是否完善，总不能每一个字符数量上面测试一下 `纯字母`，`纯数字` 和 `字母数字` 的组合，而是去使用这个范围的边界值，看看最小，最大，最小-1 和 最大+1 是否都是正常的即可知道这个范围的判断是否生效。
