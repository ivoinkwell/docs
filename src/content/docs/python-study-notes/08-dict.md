字典就是键与值相互一一对应的一种关系

## K : V

如何去理解 Key 也就是键与 Value 值的一个关系，可以使用一张表格的形式去看，现在需要一张表格去记录一个人的一些数据

|    姓名    |   张三   |
| :------: | :----: |
|    年龄    |   18   |
| 最喜欢的编程语言 | Python |

这张表格是我们能看的懂的，但是在 Python 中不能使用表格去记录，我们需要给这两个一一对应的值标上什么是键什么是值

| Key (键)  | Value (值) |
| :------: | :-------: |
|    姓名    |    张三     |
|    年龄    |    18     |
| 最喜欢的编程语言 |  Python   |

## 创建字典方法

创建字典有两种方式，更常见的会是直接创建

```python
# 空字典
d = {}

# 带初始值
d = {"name": "张三", "age": 18, "fav-lan": "Python"}
```

但是使用 `dict()` 构造函数会比直接创建的方法更多

```python
# 空字典
d = dict()

# 通过关键字参数(键必须是合法标识符)
d = dict(name="张三", age=18)

# 通过键值对序列(列表/元组)
d = dict([("name", "张三"), ("age", 18)])

# 通过另一个字典(浅拷贝)
d1 = {"a": 1, "b": 2}
d2 = dict(d1)
```

## 取值

我现在想要知道这个人的姓名，也就是从这个字典里面获取 `"name"` 这个 `Key` 的 `Value`

```python
print(d["name"])
```
