Web 前端学习手记，算是一个随时查阅的基础文档。

## 概览

从零开始学习前端开发，涵盖 HTML 基础、CSS 样式与布局、JavaScript 编程三大模块。

### HTML & CSS 基础

入门阶段，了解网页的基本结构与 CSS 样式基础。

### CSS 布局与定位

深入学习盒子模型、定位方式以及现代布局技术。

### CSS 动画与交互

使用 CSS 实现过渡动画与复杂形态变换。

### JavaScript 基础

学习 JavaScript 的变量、条件、循环、函数等核心概念。
