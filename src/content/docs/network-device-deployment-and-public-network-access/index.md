家里可以部署的机器与服务对于每个人来说是不一样的，但是虚拟机可以解决现实中设备太少的问题，也就是一台机器和一个硬盘柜，完全可以组成 `NAS + Linux开发机 + OpenVPN 服务器` 的这样一种组合……

## PVE

老旧笔记本是这个平台相当的好的硬件底座，这里我会复现使用 `ThinkPad X250` 这个笔记本在家里部署的所有设备以及其配置。

## NAS

多数人会选择黑群晖的系统去安装，但是相较于折腾一个破解系统，我觉得飞牛FnOS会是一个更好的选择，在这个系统会免费提供一个低速的公网访问方案，在自己折腾公网访问之前会是一个非常好的替代解决方案。


## Linux 开发机

作为开发机，不需要那么强的兼容性，所以选择资源消耗更低的 LXC 容器会是一个性价比更高的选择。开发机后面推送 GitHub 可能还会需要魔法，这个时候 **[clashctl](https://github.com/nelvko/clash-for-linux-install)** 这个开源项目一定会是一个比较好的选择。


## OpenVPN 服务器

家里有 NAS 和 Linux 开发机 之后，“回家”一定是一个比较头疼的问题，虽然说可以使用组网工具，但是如果家里新添了设备，或者想要访问家中的其他设备，组网需要把要用的设备加入组件的 VLAN 当中，但是使用 OpenVPN 可以直接解决这个问题，只要在服务端打开访问权限即可将家庭内网设备通过搭建的 OpenVPN 直接连接到远程电脑上。


## 公网访问

公网访问的方案有很多种，如何选择需要根据自己家庭的网络状况进行选择，如果家里有一个专门的 IPv4 ，则所有的方案可以根据我的方案进行照搬，还可以看自己是否有 IPv6 ，如果和下图中一样是 `fe80` 开头则是没有，如果是 `240x` 开头则说明有，根据下表进行自行判断，如果两个地址都没有，可以去联系运营商打开 IPv6 。
