## 概览

Linux 系统，在很多人的心里这是一个完全没有见过的系统，以至于在当时的我看来，能正常使用这个系统是一件非常有学习意义的事情。但是对于那个时候的我来说学习这个还是需要一个契机的，比如 **腾讯会议支持Linux + COVID 19**。


### 我的Linux学习

我能接触到 Linux 源于一个偶然的机会 —— 2019 年爆发的新冠肺炎疫情。当时是居家上网课，使用的是腾讯会议，而当时我用来上网课的电脑就是那台 ThinkPad X250 ，当时在下官网下载腾讯会议软件的时候偶然发现了一个全新的下载项 —— Linux ，基于当时使用 Windows 7 的体验不佳，于是直接将系统刷成了 Deepin ，这也是我使用的第一个，也是这样一个有桌面环境的发行版，才让我没在当时放弃探索与研究这些有意思的系统。


### 为什么这里用于演示的系统是 Ubuntu Server 24.04.3 LTS

 Deepin 作为一个桌面操作系统，魔改了很多 Linux 的相关概念，如果使用这个系统，他的**系统盘**和**数据盘**逻辑会让你很难理解 Linux 的文件树，所以选择一个安装完成后能够直接使用的 Linux 发行版非常重要，于是我选择了 Ubuntu 。

 选择 Ubuntu Server 还是看重安装时候设置IP地址，后续使用的命令行会很多的命令行，于是选择了 Ubuntu Server 。

 ---

 ### 为什么不使用桌面版系统

 Linux 桌面环境太多了，Gnome 和 KDE这两个一般是作为开发者的首选桌面环境，像是 Linus 这样的极客或许还是使用类似于 XFCE 这样的轻量桌面环境。所以在这种错综复杂的桌面环境下，使用桌面环境相比于直接使用命令行，或许玩了一天也不过就是给桌面环境改改设置而已。

 我确实是从桌面版，逐渐转变为桌面用 Windows ，开发依旧 Linux ，不过是 SSH 连接罢了。
